# LocalOps

LocalOps is a full-stack web application for small service businesses to manage customers and appointments.

## Purpose

LocalOps helps small service providers organize customer information and appointment schedules in one place.

## Target Users

- Small service businesses
- Freelancers
- Local service providers

## Planned Features

- User authentication
- Customer management
- Appointment management
- Dashboard summaries
- Responsive design

## Tech Stack

- Next.js with App Router
- TypeScript
- MongoDB Atlas
- Auth.js or Clerk
- Tailwind CSS
- Vercel

## Team Members

- Gilda — Full-stack developer

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
